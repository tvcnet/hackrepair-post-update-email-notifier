# Contributing

Use the canonical nested checkout. Read PROJECT.md and MAINTAINING.md before edits. Keep stored settings, hook names, entrypoint and installed directory stable. Add behavior-focused tests for meaningful changes; use Mailpit for local mail tests. Run shared PHPCS, applicable regressions, syntax and package checks. Keep docs aligned with implementation. No development files, Git history or secrets in release ZIPs. Do not replace published tags or assets. Consider the Codex Security review reminder separately.

Use [GitHub Discussions](https://github.com/tvcnet/hackrepair-post-update-email-notifier/discussions) for questions, ideas and community support. File reproducible bugs in [Issues](https://github.com/tvcnet/hackrepair-post-update-email-notifier/issues). Report security concerns privately using [SECURITY.md](SECURITY.md).
