Everyone who should know, doesn't always hear.

Without a nudge, people find out a page changed when something goes wrong. A short, branded email to the right roles fixes that, without the whole site getting a message every time you fix a typo.

  • Editors

    Want to know when a reference page changes, so their own work stays right.

  • Clients

    Like to review revised pages instead of discovering them later.

  • Site owners

    Need a useful record of what was announced, and to whom.

  • You

    Want routine edits to stay routine, with no accidental mass emails.

What it does

Open Settings › Post Update Notifier, choose roles, set up the email, and announce updates from the editor.

  • Pick which WordPress roles get notified, and optionally leave out the person updating
  • A checkbox in the editor for each update, with a count of who will be emailed
  • Quiet by default, or switch the default so updates send unless you opt out
  • A per-post cooldown, so repeated saves do not send bursts
  • Larger lists go out in background batches, so saving stays fast
  • Say what changed with [change_summary] and a revision link
  • Branded HTML email with your own subject, message, colors, footer and sender
  • Preview an email or send yourself a test before anyone else sees it
  • An optional email log with failures, skip reasons and CSV export
  • Site Health checks and WP-CLI commands for the technical side

Announce on purpose

Notifications are intentional. After each update the choice goes back to the site default, so routine edits stay quiet.

Mail you can trust to behave.

  • Quiet by default
  • One email per person
  • No SMTP credentials stored
  • Updates from GitHub

Each recipient gets an individual message through your site’s own WordPress mail setup, so people never see each other’s addresses. If a process stops during a send, the plugin does not resend automatically, which favors avoiding duplicates over guaranteeing delivery.

Acceptance for sending is not a delivery receipt, so send a test and check your mail service’s logs. The only outside requests are update checks against this project’s GitHub releases. If you think your site has been hacked, The Hack Repair Guy can help.

Install it in a minute

  1. Download the zip from the button below.
  2. In WordPress, open Plugins › Add New › Upload Plugin, choose the zip and activate it.
  3. Open Settings › Post Update Notifier, choose the roles to notify, and send yourself a test email.
  4. Edit published content, untick Don’t send email notifications for the update you want to announce, and save.
