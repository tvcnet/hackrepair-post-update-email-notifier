## Migration contract

Use repository tvcnet/hackrepair-post-update-email-notifier and tag v1.5.0. Required asset hackrepair-post-update-email-notifier.1.5.0.zip; root hackrepair-post-update-email-notifier/. No tag/branch source archives. Existing Google Drive installations cannot automatically discover the GitHub-only updater until they receive this code. Recommended initial migration is a one-time manual upload. An alternate Drive bridge would require deliberate manifest changes and separate approval; no such change is included.

## Do not silently change

Saved roles, subject/message templates, From/Reply-To, retained logs, skip meta, data ownership, repository owner, recipient choices and available developer hooks. Subject tags are applied at construction without overwriting templates. Existing acceptance/delivery limits must be documented. Legacy site-local log timestamps need a separate migration before switching storage semantics. Keep old archives untouched.
