# 1.5.0

- Standardized the admin interface with THRG branding, version beside the title, native View Details, original banner and companion plugin guide.
- Added domain/plugin email subjects and a full-width HTML wrapper while preserving existing templates and settings.
- Moved update discovery to validated GitHub release assets in the existing tvcnet repository, with clearer update-check errors.
- Simplified the plugin bootstrap and settings rendering, and added focused regressions, PHP 7.4/8.3 CI and permission-safe packaging.

**Upgrading from Google Drive-based versions:** Download this release ZIP and upload it through Plugins → Add New → Upload Plugin once. Subsequent versions can be discovered through the GitHub updater. The installed folder and existing settings are preserved.

Verified locally on WordPress 7.1 / PHP 8.2.33 with Mailpit. Email acceptance does not confirm external delivery. See PROJECT.md and the execution evidence for test scope and remaining limits.
