# 1.5.1 — unpublished candidate, superseded by 1.6.0

- Fixed the Export Log fatal error (`gmgmdate()`); the CSV is now sent before the settings page renders, with PHP 8.4-safe `fputcsv()` calls.
- Test email, bulk test, settings save and update-check buttons report failures accurately and clear stale feedback on retry.
- Settings section headings, card bodies and form tables share one width.
- Consolidated duplicate helper, sanitizer, logging and export fallbacks onto the service classes; removed the obsolete download-button script, an unused localized nonce and dead CSS. Public wrappers, settings keys, meta key and hooks are preserved.

Installed folder, PHP entrypoint and existing settings are unchanged. Upgrades from 1.5.0 are discovered through the GitHub updater once the release is published.
