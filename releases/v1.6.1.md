# 1.6.1 — unpublished review candidate, superseded by 1.6.2

- Added contextual help beside notification rules, recipients, subject/message, branding, sender settings, preview/test actions, CSV export and bulk testing.
- Removed the settings-page Update status container and its manual-check code; plugin updates remain available through WordPress’s Plugins screen.
- Refresh the admin stylesheet URL when the CSS file changes so repeat review installs show the current design.
- Added a compact post-editor checkbox illustration beside Default for each update; it stacks below the dropdown on narrow screens.
- Reduced repeated settings descriptions; retained the placeholder reference, live counts, editor illustration and test/reset warnings. Logging help now includes personal data export and erasure.
- Started with Default for each update: explains both policies, the per-post choice, Save Notifications and recipient requirements.
- Help supports hover, keyboard focus and tap, Escape/outside dismissal, viewport-aware positioning and a native no-JavaScript fallback.
- Includes the unreleased 1.6.0 features, queue-recovery fixes and compatibility work. Supersedes the unpublished 1.6.0 candidate; the public release was 1.5.0 during this review.

No notification settings, stored choices or delivery behavior are changed by opening help. This review build was not published; its changes are included in 1.6.2.
