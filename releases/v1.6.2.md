# Version 1.6.2

> Historical record: version 1.6.2 was superseded by 1.6.3 on October 20, 2026. Its GitHub release and tag were deleted at the user's request; local ZIPs and recoverable backups are retained.

## What’s new

- Choose whether editors opt in or out of email notifications, which publication events qualify, and how long to wait between notifications for the same post.
- Send larger recipient lists in WP-Cron batches, with saved progress, bounded scheduling recovery, and tools to inspect or retry pending work.
- Preview messages without sending, include a summary of content changes, and link to the revision comparison.
- Get clearer settings with contextual help, a visual guide to the editor checkbox, and less repeated text.
- Use WordPress personal data export/erasure, WP-CLI commands and Site Health diagnostics for this plugin.

## Fixes and cleanup

- Fixed CSV export and improved saved-template defaults, failure feedback and skipped-update reporting.
- Hardened queue recovery against interrupted or overlapping workers and corrected sender-domain checks.
- Improved admin stylesheet cache handling and removed the separate settings-page Update status panel. Plugin updates remain available through the standard WordPress Plugins screen.

This release includes the previously unpublished 1.5.1, 1.6.0 and 1.6.1 review builds.

**Requirements:** WordPress 6.6 or later; PHP 7.4 or later.

**Email delivery:** Acceptance for sending does not confirm inbox delivery. Background sending requires working WP-Cron or a server cron job. Recipients with an uncertain transport outcome are not automatically sent the same message again.

## Installation

Download `hackrepair-post-update-email-notifier.1.6.2.zip` from this release and upload it through Plugins → Add New → Upload Plugin, or use WordPress’s normal plugin update flow. Existing settings are preserved. Older Google Drive updater installations need a one-time manual upload to migrate to GitHub updates.
